\section*{Reproducibility and Data Availability}

All protocols, dated amendments, raw outputs, analysis scripts and SHA-256 hashes of locked inputs are kept in the project repository. The baseline, the robustness and $J$-condition studies and the survey analyses run offline on a CPU; the stored outputs of the main and robustness studies were re-derived byte-for-byte in a fresh virtual environment on the same machine, which is not an independent reproduction. The survey labels are AI-coded and are stored with their \code{file:line} evidence. The LLM experiments (RQ3) need an OpenAI API key and use closed models whose output is not guaranteed to be deterministic, so a rerun will not match line by line; the analysis scripts recompute every estimate from the raw files without any API access. The RQ3 experiments cost under two US dollars in API fees in total (estimated from logged token counts).
